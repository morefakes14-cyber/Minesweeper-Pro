💣 Minesweeper Pro: Neumorphic Edition

مین‌روب پرو یک بازسازی مدرن، سبک و زیبا از بازی نوستالژیک و کلاسیک Minesweeper است. این پروژه با استفاده از معماری Vanilla JavaScript و طراحی بصری Neumorphism ساخته شده تا تجربه‌ای روان و لذت‌بخش را در مرورگر شما فراهم کند.
✨ ویژگی‌های کلیدی (Core Features)
🛡️ امنیت کلیک اول (First-Click Safety)

دیگر خبری از باخت‌های ناعادلانه در ثانیه اول نیست! الگوریتم تولید بمب تنها پس از اولین کلیک شما فعال می‌شود و تضمین می‌کند که خانه انتخاب شده و تمام ۸ خانه مجاور آن ۱۰۰٪ امن باشند.
🚩 سیستم پرچم‌گذاری هوشمند

با استفاده از راست‌کلیک، مین‌های احتمالی را علامت‌گذاری کنید. خانه‌های پرچم‌گذاری شده برای جلوگیری از خطای انسانی، قفل می‌شوند و تا زمانی که پرچم را برندارید، باز نخواهند شد.
🏆 ثبت رکورد جهانی (Local Best)

بهترین زمان شما (Best Score) به صورت خودکار در localStorage مرورگر ذخیره می‌شود. با هر بار بازگشت به بازی، رکورد قبلی خود را مشاهده کنید و برای شکستن آن تلاش کنید.
🎨 طراحی مدرن (UI/UX)

    Neumorphic Design: استفاده از سایه‌های نرم و عمق بصری برای ایجاد حس لمس دکمه‌های فیزیکی.

    Responsive: هماهنگ با ابعاد مختلف نمایشگر.

    Color Coding: اعداد با رنگ‌های استاندارد برای تشخیص سریع تعداد بمب‌های مجاور.

🕹 راهنمای بازی (How to Play)
هدف بازی

هدف شما باز کردن تمام خانه‌های صفحه است، به جز خانه‌هایی که حاوی مین هستند. اگر تمام خانه‌های امن را باز کنید، برنده می‌شوید.
کنترل‌ها

    کلیک چپ: باز کردن یک خانه مشکوک.

    راست کلیک (یا Long Press در موبایل): گذاشتن یا برداشتن پرچم قرمز (🚩).

    دکمه شروع مجدد: ریست کردن صفحه و شروع یک رقابت جدید.

قوانین و علائم

    اعداد: هر عدد (مثلاً ۲) نشان می‌دهد که در ۸ خانه اطراف آن، دقیقاً ۲ مین وجود دارد.

    خانه خالی: اگر خانه‌ای باز شود و هیچ عددی نداشته باشد، بازی به صورت زنجیره‌ای تمام خانه‌های خالی مجاور را برای شما باز می‌کند.

    بمب (💣): برخورد با این آیکون یعنی پایان بازی!

🚀 نصب و اجرا

این پروژه کاملاً Portable است و نیاز به هیچ پیش‌نیازی (مانند Node.js یا سرور) ندارد.

    کد موجود در فایل index.html را کپی کنید.

    یک فایل جدید به نام index.html در سیستم خود بسازید.

    فایل را ذخیره کرده و آن را با یکی از مرورگرهای مدرن (Chrome, Firefox, Edge, Safari) باز کنید.

🛠 جزئیات فنی (Technical Overview)

    Logic: استفاده از الگوریتم Flood Fill (بازگشتی) برای باز کردن خانه‌های خالی مجاور.

    State Management: مدیریت وضعیت بازی (در حال اجرا، برد، باخت) با استفاده از متغیرهای Global و Logic کنترلرها.

    Styling: استفاده از CSS Variables برای مدیریت تم رنگی و انعطاف‌پذیری در تغییرات آینده.
